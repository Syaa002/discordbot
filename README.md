# 🤖 Ambanime Discord Bot — Baseline Version

Bot Discord dasar yang telah di-reset ke pengaturan awal (baseline), hanya menyisakan perintah dasar seperti `.ping` dan status bot.

## 📌 Prefix Perintah
- **`.`** (Titik) — Default
- **`!`** (Tanda Seru) — Alternatif / kompatibilitas awal

---

## ⚡ Daftar Perintah Aktif

| Perintah | Deskripsi | Contoh |
| :--- | :--- | :--- |
| **`.ping`** / **`!ping`** | Mengecek status keaktifan bot serta mengukur latensi pesan & API Discord. | `.ping` |
| **`.status`** / **`.info`** | Menampilkan informasi dasar bot (uptime, status API, tag bot). | `.status` |

---

## 🚀 Panduan Update di Bot-Hosting.net

1. Buka dashboard [bot-hosting.net](https://bot-hosting.net) (deployment **AmbanimeOfficial**).
2. Masuk ke menu **Files** > buka **`index.js`**.
3. Hapus seluruh isinya, lalu **Copy & Paste** kode terbaru dari `D:\discordbot\index.js`.
4. Klik **Save Content**.
5. Buka tab **Console**, lalu klik **Restart**.
